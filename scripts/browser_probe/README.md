# Manuscript: браузерное приложение

Браузерный аналог `scripts/end_to_end_app.py`. Этапы выполняются существующей
Python-библиотекой в Pyodide, ONNX — через ONNX Runtime Web. Сервер раздаёт
страницу и файлы моделей; изображения и выбранные папки остаются на устройстве.

## Подготовка и запуск

```bash
npm install --prefix /private/tmp/manuscript-pyodide-check onnxruntime-web@1.30.0

env/bin/python scripts/browser_probe/prepare.py \
  --ort-dist /private/tmp/manuscript-pyodide-check/node_modules/onnxruntime-web/dist

env/bin/python scripts/browser_probe/serve.py \
  --directory /private/tmp/manuscript-pyodide-check --port 8014
```

Открыть <http://127.0.0.1:8014>. Для другого адреса передайте его в
`prepare.py --base-url`. Нужен браузер с JSPI; проверялось в Chrome.

Скрипт собирает wheel из текущего checkout, копирует интерфейс и ORT Web,
добавляет официальный реестр. Локальные модели для подготовки не обязательны:
их можно выбрать прямо на странице.

Чтобы добавить свои комплекты в выпадающие списки сайта:

```bash
env/bin/python scripts/browser_probe/prepare.py \
  --ort-dist /path/to/onnxruntime-web/dist \
  --model-folder /path/to/model-bundle \
  --model-folder /path/to/another-bundle
```

Для прежнего примера с PP-OCRv6 Tiny и Kraken Tiny можно дополнительно передать
`--detector-dir /path/to/PP-OCRv6_tiny_det` и
`--recognizer-dir /path/to/kraken-ppocrv6-tiny`. Они появятся в списках пресетов.

## Возможности

- Пресеты из реестра и выбор локальной папки отдельно для каждого этапа.
- Детекторы, распознаватели и корректоры обнаруживаются из установленных модулей
  Manuscript; списка «поддерживается в браузере / не поддерживается» нет.
- По одной модели на этап; новая модель заменяет предыдущую и освобождает её сессию.
- Этап можно выключить. Лейаут — ReadingSorting или SimpleSorting.
- Параметры детекции, уровни распознавания, подготовка областей, размер батча,
  настройки лейаута и коррекции, соответствующие исходному приложению.
- CPU/WASM и WebGPU, визуализация, текст, статистика по этапам, экспорт TXT/JSON.
- Остановка завершает worker и освобождает его память. После остановки модели
  нужно выбрать заново; файлы не сохраняются между перезагрузками страницы.

Поле «Батч» по умолчанию равно 0: используется размер, заданный моделью
(для TRBA — 128). Значение 1 запускает отдельный вызов на каждый регион и может
сильно замедлить распознавание целой страницы.

## Проверка при выборе модели

Выберите папку с `model.json` в корне, как в обычном приложении:

```json
{
  "model_classes": ["PPOCR"],
  "artifacts": {
    "weights": {"filename": "detector.onnx"},
    "config": {"filename": "detector.json"}
  }
}
```

Файлы читаются частями в файловую систему worker. Передаются объявленные
артефакты и сопутствующие `.data`, а не все исходники из вложенных папок.
Проверяются пути, наличие файлов и, если указаны, размер и SHA-256.
Сессии и пробный инференс при выборе не запускаются. Пресет выбирается прямо
в списке; его файлы скачиваются при первом нажатии «Распознать». Модель запускается
сразу на выбранном изображении. Ошибки зависимостей, графа или памяти показываются
при запуске; подробности остаются в журнале. После смены устройства сессия будет
создана заново при следующем распознавании.

`serve.py` отдаёт пресеты с того же адреса, что и страницу. Сервер скачивает
только файлы из подготовленного каталога, передаёт их потоком и сохраняет
проверенные по размеру и SHA-256 копии в локальном кэше. Это позволяет использовать
GitHub Releases, чьи прямые ссылки браузер блокирует из-за CORS. Обычный
`python -m http.server` не обеспечивает такой маршрут. OCR остаётся в браузере.

При размещении на другом сайте раздавайте модели с его домена или используйте
хранилище с CORS. Большие модели должны целиком помещаться в память браузера;
чтение частями не отменяет этого ограничения.

## Проверки

```bash
env/bin/python -m pytest scripts/browser_probe/test_app.py -q
```

`prepare.py --checks` дополнительно создаёт небольшие графы для проверки
моста, типов тензоров, загрузчика и external data; требуется пакет `onnx`.
В worker их можно запустить сообщением `{id, action: "checks"}`.

Весь каталог `scripts/browser_probe` — отдельный пример, он не включается в
wheel библиотеки. Изменять библиотеку для запуска интерфейса не требуется.
